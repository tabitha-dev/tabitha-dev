## 👩‍💻 About Me

I’m a **frontend-focused software engineer** working at the intersection of **software engineering, healthcare operations, AI quality, and workflow automation**.

With more than **eight years of healthcare revenue-cycle and administrative experience**, I bring practical domain knowledge into the products I build. I understand the workflows behind claims, denials, eligibility, authorizations, medical billing, payer rules, AR aging, and HIPAA-aware data handling—not just the interfaces surrounding them.

Today, I design and build responsive web applications, healthcare dashboards, automation tools, AI review workflows, client websites, and implementation-ready prototypes.

My work combines:

- Clean, responsive frontend development
- Healthcare and revenue-cycle workflow knowledge
- Structured and unstructured data validation
- Human-in-the-loop AI quality review
- Accessibility and mobile-first design
- Workflow automation and API integration
- Technical documentation and stakeholder communication

## 🧭 How I Work

- **Start with the workflow** — understand the user, operational context, constraints, and desired outcome
- **Translate complexity into clear interfaces** — organize information so users can act quickly and confidently
- **Build for real use** — prioritize responsiveness, accessibility, maintainability, and practical implementation
- **Validate the details** — test edge cases, data quality, permissions, failure states, and workflow handoffs
- **Document decisions** — create implementation guidance, QA notes, architecture explanations, and stakeholder-ready handoffs
